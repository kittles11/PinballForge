# 多分辨率适配审计（Task 010，2026-09-07）

> 方法：静态审计 + 纯 Node 自检锁定（`tools/selfchecks/selfcheck-resolution.ts`）；
> 引擎：Cocos Creator 3.8.x 2D，无 Widget，全弹窗纯代码 Graphics UI。

## 适配策略（引擎层）

- designResolution **720×1280、fitHeight=true**（`settings/v2/packages/project.json`，自检 JSON 真解析）；
- fitHeight 语义：**可视高度恒 1280** 设计像素，可视宽 = 屏宽/屏高 × 1280（16:9 恰为 720，更瘦/更胖屏按比例伸缩）；
- 弹窗适配靠两条约定：**遮罩超大铺满** + **面板尺寸收敛**（无锚点系统参与）。

## 视口几何 × 商店内容预算

商店内容需求 `need = max(面板 620, 稀有卡跨度 540) + 40 呼吸 = 660`；
`scale = min(1, 可视宽 / 660)`，由 `ShopDialog.applyScale()` 在 openShop 时应用。

| 档位 | 屏纵横 | 可视宽（设计px） | 结果 |
|---|---|---|---|
| 基线 720×1280 | 9:16 | 720.0 | 免缩放 |
| iPhone X~14 类 | 19.5:9 | 590.8 | ×0.895 |
| 安卓主流窄屏 | 20:9 | 576.0 | ×0.873 |
| 极窄带影院屏 | 21:9 | 548.6 | ×0.831 |
| 平板 | 3:4 | 960.0 | 免缩放（不放大，钳 ≤1），面板居中宽裕 |
